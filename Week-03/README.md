# Week 3: Data Cleaning and Preprocessing Pipeline

## Objective
Develop a data cleaning and preprocessing pipeline for Beauty and Wellness review data.

## Dataset
Amazon Beauty Product Reviews sample dataset.

## Work Completed
- Loaded and inspected the dataset using Pandas.
- Checked missing values, duplicate records, ratings, and data types.
- Removed exact duplicate records.
- Cleaned review titles and text.
- Converted Unix timestamps to UTC datetime values.
- Created a review-length feature.
- Performed data validation and exported cleaning results.

## Tools Used
- Python
- Pandas
- Regular Expressions
- HTML utilities
- Google Colab

## Files
- `Week_03_Data_Cleaning_Preprocessing.ipynb` — preprocessing notebook.
- `week3_cleaning_summary.csv` — cleaning summary.

## Outcome
Prepared a cleaned dataset for further analysis, subject to the validation results recorded in the notebook.
