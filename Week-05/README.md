# Week 05: Predictive Modeling

This week focuses on developing and evaluating Machine Learning models for sentiment classification in the Beauty and Wellness industry.

## Work Completed
- Sentiment classification using customer reviews.
- Text feature extraction using TF-IDF.
- Logistic Regression, Multinomial Naive Bayes and Decision Tree implementation.
- Class balancing experiment using Balanced Naive Bayes.
- Model evaluation using Accuracy, Precision, Recall, Weighted F1 and Macro F1.
- 5-fold cross-validation.
- Model comparison and performance analysis.

## Final Model
Logistic Regression was selected as the primary model based on its balanced performance across sentiment classes and its Macro F1-score.
